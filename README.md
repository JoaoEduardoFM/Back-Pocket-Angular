### É uma aplicação planejada por mim, onde realizo o CRUD de um gerenciador de usuários.

## Alguns campos no modelo principal são:

+ id 
+ nome
+ cpf
+ login
+ senha
+ número
+ envio de e-mail
+ cadastro Produto
+ controle de Estoque
+ gerenciamento de usuário
